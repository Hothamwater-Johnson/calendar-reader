# Errors

A log of errors that took **more than two turns to fix**. Quick fixes don't belong here — this is for the stubborn ones, so the same trap isn't fallen into twice.

## Format

```
## YYYY-MM-DD — <short title>
**Symptom:** What went wrong / the observed failure.
**Root cause:** What was actually causing it.
**Fix:** What resolved it.
**Lesson:** What to check first if this recurs.
```
